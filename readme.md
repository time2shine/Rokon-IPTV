# 📺 Rokon IPTV

A curated and automatically maintained **M3U IPTV playlist** featuring Bangla and international live television channels.

The playlist is organized by category and includes channel names, logos, group information, and stream URLs for use with IPTV players.

## 🚀 Quick Start

Copy one of the playlist URLs above.

In your IPTV player:

1. Add a new playlist/source.
2. Select **M3U Playlist** or **Playlist URL**.
3. Paste the URL.
4. Save and refresh the playlist.

Example:

```text
https://tinyurl.com/rokon-iptv
```

## ⚠️ Stream Availability

Stream URLs are collected from publicly accessible sources.

Individual channels may become temporarily unavailable, change their stream address, introduce geographic restrictions, or stop working without notice.

The playlist is periodically refreshed to remove or replace unavailable sources where possible.

---

## ⚖️ Disclaimer

This repository does not host video or television streams.

It contains playlist metadata and links that point to third-party streaming servers. Availability, ownership, licensing, and distribution rights of those streams remain with their respective providers.

If you are a rights holder and believe a link listed in this repository should be removed, please open an issue with the relevant channel or URL so it can be reviewed.

This project is maintained for personal, educational, and technical experimentation with IPTV playlist management.
